# 校園點餐系統

提供學生線上點餐、商家接單備餐、管理員管理查詢的校園點餐系統。本專案同時是研究案例：以 Waterfall 流程走過需求、設計、實作、測試與交付，記錄 AI 在各階段參與了什麼、人做了哪些判斷，以及哪些地方後來需要重做。

## 文件導覽

依閱讀順序排列，版本與修訂日期見各文件開頭。

| 文件 | 用途 |
| --- | --- |
| [PRD](docs/PRD.md) | 產品目標、範圍、功能需求與驗收方向 |
| [SRS](docs/SRS.md) | 軟體需求規格，是設計與驗收的需求依據 |
| [SRS 決議紀錄](docs/SRS_決議紀錄.md) | SRS 待決議事項的決議結果與後續範圍變更 |
| [SAD](docs/SAD.md) | 系統架構設計入口：架構概覽、關鍵規則，以及各模組文件與圖表索引 |
| [UML 系統架構圖](docs/UML_系統架構.md) | 一張圖看系統由哪幾塊組成、誰依賴誰 |
| [術語一致性檢查](docs/術語一致性檢查.md) | PRD、SRS、SAD 之間的術語問題與處理狀態 |
| [領域詞彙](CONTEXT.md) | 已確認的領域用語及應避免的說法 |
