## 1. 檢查範圍與判定方式

本報告比對以下文件，共整理 22 項術語問題或統一建議：

- [Waterfall PRD v0.5](./PRD.md)
- [SRS v0.6](./SRS.md)
- [SAD v0.6](./SAD.md)，包含其連結的 `SAD/00`～`14` 模組與共通設計文件。

檢查分為三類：同一概念使用不同名稱；同一名稱有不同意義，或定義與使用方式不一致；使用前未定義，或定義不足以作出一致判斷。「未定義」不只檢查詞彙表，也檢查正文是否已說明含義與判斷條件。

同義用字、實際矛盾、一詞多義及版本間的需求細化分開標示；SRS 已補充清楚、但 PRD 尚未同步的內容，不直接視為三份文件均未定義。以下內容除明示已確認的決議外，均為發現時的建議。原始 PRD、SRS、SAD 已依 TD-02 移除客製化選項，並依 TD-03 精簡商品模組及對齊商品相關術語。下表保留發現時的問題，已處理項目在建議或確認決議欄標示，最終做法以〈已確認決議〉為準。

## 5. 已確認決議

### TD-01 商品狀態只有上架與下架

- 確認日期：2026-11-05。
- 使用者原意：「商品應該只有上架與下架」。
- 商品狀態僅有 **上架、下架**，不另設「停用」「停售」「售完」或「可下單」等商品狀態。
- 是否能成立訂單仍須通過庫存及其他既有送單條件；這些是驗證條件，不新增商品狀態。
- 後續 TD-03 已確認移除獨立售完旗標；庫存歸零、釋回、補入或每日重置均不改變商品上架／下架狀態。
- 涉及項目：TA-09、TB-01、TC-02、TC-03。

### TD-02 移除客製化選項功能

- 確認日期：2026-11-05。
- 使用者原意：「客製化需求移除」。
- 移除整個客製化選項功能，包含選項群組、選項加價、最少／最多選取數及選項上下架。
- FR-008／AC-008 保留編號並標示已廢止，不再實作或驗收。
- Catalog 調整為商品模組；價格小計為商品單價乘數量，訂單合計為各筆小計之和。商品、數量與備註保留。
- 已同步 PRD、SRS、SAD 及需求追溯；選項資料類別、資料表、API、請求欄位與相關測試設計同步移除。詳見 [需求範圍變更紀錄 R-01](./SRS_決議紀錄.md#需求範圍變更紀錄)。

### TD-03 商品模組精簡與術語對齊

- 確認日期：2026-11-05；使用者確認採用前一輪商品模組減法建議並要求名詞概念對齊。
- 移除商品圖片與分類；商品模組只管理商品名稱、商品單價及上架／下架，保留商家歸屬與並行修改保護。
- 商品狀態只有上架／下架（listed）；本次庫存模式原有有限庫存／不限量，後續 TD-05 已統一為有限庫存。移除獨立售完開關，庫存不足是本次送單拒絕原因。
- 商品資料版本只保留 version；商品單價統一使用 unitPrice／unit_price。報價與訂單快照保存自己的商品名稱與商品單價，送單重新比較實際內容與資格。
- 已同步 TA-09、TB-01、TB-02、TC-02、TC-03、TC-05；原問題敘述保留供追溯。完整用語見 [領域詞彙](../CONTEXT.md)，需求變更見 [R-02](./SRS_決議紀錄.md#需求範圍變更紀錄)。

| 邊界情境 | 統一結果 |
| --- | --- |
| 上架但可用量為 0 | 商品仍上架；送單因庫存不足被拒 |
| 下架且庫存足夠 | 商品仍下架；送單因商品下架被拒 |
| 下架後補庫存、釋回或每日重置 | 只更新庫存，不自動上架 |
| 下架或改價前已有訂單 | 原訂單及其成立快照不變，不因下架取消或釋回資源 |
| 商品資料版本變更但實際確認內容相同 | 重新驗證上下架、庫存等資格；不僅因版本不同要求重確認 |

### TD-04 下架商品從點餐者菜單隱藏

- 確認日期：2026-11-05；使用者原意：「下架商品要隱藏」。
- 點餐者菜單只顯示上架商品，公開菜單回應由後端以 listed=true 篩選，不包含下架商品。
- 商家商品管理仍可查看本店下架商品並重新上架；隱藏不代表刪除商品。
- 舊畫面加入與舊購物車送單仍須重驗商品狀態；已成立訂單的明細及快照依原權限顯示。
- 已同步 PRD／SRS FR-007、AC-007、SAD 商品與購物車契約、API、前端、驗證與追溯。詳見 [需求範圍變更 R-03](./SRS_決議紀錄.md#需求範圍變更紀錄)。

### TD-05 僅保留有限庫存

- 確認日期：2026-11-05；使用者原意：「只留有限庫存」。
- 所有商品均採有限庫存；可用量與每日預設量均為必要的非負整數，不接受空值，不提供不限量或模式選擇。
- 移除資料與介面的庫存模式欄位、模式切換規則及略過庫存保留的例外；每張訂單的每項商品都須檢查與保留庫存。
- 每日重置、接單轉耗用、取消釋回、跨日隔離與上下架分離規則維持；下架商品仍從點餐者菜單隱藏。
- 已同步 PRD／SRS FR-009、AC-009、操作紀錄清單、SAD 資源與訂單交易、資料模型、API、驗收追溯及詞彙表。歷史決議中的不限量規則由本決議取代；詳見 [R-04](./SRS_決議紀錄.md#需求範圍變更紀錄)。

### TD-06 時段規則精簡

- 確認日期：2026-11-05；使用者採用 Resources 減法建議的前三項。
- 預訂截止固定為時段開始前 10 分鐘，移除商家可調截止分鐘數；商家接單截止仍為訂單時段結束時間。
- 容量不得低於已占用份數，違規修改整次拒絕，原容量與訂單維持；已有占用時不得設容量為 0。
